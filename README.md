# Agent Kit Manager

管理跨工程复用的 skill、MCP 和 agent 规则条目，并同步 `agent-kit` 配置仓库。

## 安装本 Skill

将本 README 交给你的 agent，并请它依次完成：

1. 按 [setup.md](references/setup.md) 创建或连接你自己的 `agent-kit` 仓库，并配置 `~/.agent-kit`。
2. 按 [skill_setup.md](references/skill_setup.md) 将 [agent-kit-manager](https://github.com/ThinkerLu/agent-kit-manager) 纳入该仓库，并链接到当前 agent 的全局 skill 目录。
