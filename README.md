# Agent Kit Manager

**目标**：统一管理 skill、MCP 等跨工程复用资产，按需引入，减少项目上下文大小。

管理动作：从 kit 检索并引入 skill 到工程、把可复用 skill 创建入库、整理 kit 分类，以及配置 MCP 与规则条目。

## 安装本 Skill

将本 README 交给你的 agent，并请它依次完成：

1. 按 [setup.md](references/setup.md) 创建或连接你自己的 `agent-kit` 仓库，并配置 `~/.agent-kit`。
2. 按 [skill_setup.md](references/skill_setup.md) 将 [agent-kit-manager](https://github.com/ThinkerLu/agent-kit-manager) 放入该仓库的 `skills/global/` 分类，并链接到当前 agent 的全局 skill 目录。
